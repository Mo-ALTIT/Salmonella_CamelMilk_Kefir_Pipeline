# Predictive Modeling of Salmonella Inactivation in Camel Milk Kefir

This repository contains the complete pipeline used for:

- Primary kinetic modeling
  - Bigelow
  - Weibull

- Secondary modeling
  - Response surface regression

- One-step global modeling

- Machine learning modeling
  - Random Forest
  - XGBoost
  - RVM

- Model interpretation
  - SHAP analysis

## Dataset

The dataset contains:

- KEFIR GRAINS %
- Fermentation time (h)
- Storage Temperature (C)
- Ph
- T. Acidity (%)
- Salmonella counts (Log CFU/mL)
